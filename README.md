# 鞘翅革新 / Elytra Renewed

## 中文版

**鞘翅革新** 是一个为《我的世界》Java 版 Fabric 26.2 打造的轻量模组，让鞘翅滑翔不再依赖烟花火箭。

### 功能

- 滑翔时按住前进键（默认 W），即可获得向前的加速度
- 水平速度上限为 **30 格/秒**，长距离滑翔不再需要烟花
- 松开前进键后停止加速，速度自然衰减，随时可以停下来
- 加速会消耗饱食度，约 **16 秒消耗 1 点**
- 饱食度 ≤ 6 时无法加速，与原版无法疾跑的门槛一致

### 安装

1. 安装 Fabric Loader 0.19.5 或更高版本
2. 安装 Fabric API 0.160.0+26.2 或更高版本
3. 将本模组放入 `mods` 文件夹
4. 启动游戏，穿上鞘翅即可体验

### 开发环境

- Minecraft 26.2
- Fabric Loader 0.19.5
- Fabric API 0.161.0+26.2
- Java 25

## English Version

**Elytra Renewed** is a lightweight Fabric mod for Minecraft Java Edition 26.2 that lets you glide with your elytra without relying on firework rockets.

### Features

- Hold forward (default: W) while gliding to gain forward acceleration
- Horizontal speed cap of **30 blocks/second**, making long-distance gliding possible without fireworks
- Release the forward key to stop accelerating and slow down naturally
- Accelerating consumes hunger, roughly **1 hunger point every 16 seconds**
- Cannot accelerate when hunger is ≤ 6, matching the vanilla sprinting threshold

### Installation

1. Install Fabric Loader 0.19.5 or later
2. Install Fabric API 0.160.0+26.2 or later
3. Drop the mod into your `mods` folder
4. Launch the game, equip your elytra, and glide

### Development Environment

- Minecraft 26.2
- Fabric Loader 0.19.5
- Fabric API 0.161.0+26.2
- Java 25
